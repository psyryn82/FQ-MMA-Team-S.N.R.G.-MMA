First-time setup notes

If sign-in fails, confirm the latest schema is applied and Google is enabled in Authentication → Sign In Providers with valid OAuth credentials. Never use a service_role key in this file.

Administrator sign in

Only approved FQ MMA administrators can access this dashboard.

Dashboard

Homepage content

The homepage uses one JSON document named public. Keep the fields and structure intact. For fighters, events, schedule, live-stream pricing, MMA event media, Sasha’s portfolio, purchase history, and chat, use their tabs.

Sasha’s booking requests

Review requests first. Approving a request does not charge the customer. Add a Stripe payment link and send it by email only after you are ready to approve the booking.

Ticket purchases

Read-only payment records confirmed by the signed Stripe webhook. Pending checkouts are not proof of payment.

Media & portfolio sales

Read-only payment history for MMA event media and Sasha’s portfolio. Only confirmed Stripe webhook payments should grant access.

MMA event media + Sasha’s portfolio purchases

Access management

Read-only view of paid digital-content purchases used to determine access. This screen does not manually grant or revoke access; only confirmed payment records count as paid.

Stream sales

Read-only history of MMA event live-stream purchases. Only confirmed Stripe webhook payments should grant access. Live-stream testing remains separate and is not performed here.

MMA event live-stream purchases

Media Catalog & Uploads

Manage two separate catalogs. Free previews are public; paid files are uploaded to private storage and delivered only after Stripe confirms payment. Maximum file size: 50 MB.

Live chat inbox

Inbox for signed-in members. Anonymous visitor chat is not enabled.
