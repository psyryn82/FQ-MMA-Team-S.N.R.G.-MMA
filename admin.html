One-time setup needed

This dashboard uses Supabase. Run the updated supabase-schema.sql in Supabase SQL Editor to create the additional tables and media bucket. Confirm Google is enabled in Authentication → Sign In Providers. Never use a service_role key here.

Administrator sign in

Only accounts explicitly approved as FQ MMA administrators can access the dashboard.

Dashboard

Homepage content

Edit the homepage data saved under the public key. Keep valid JSON and preserve the existing structure. Changes appear on the public site after its next load.

Manage fighters

Add fighters and update their public profile details.

Manage events

Create and maintain event listings.

Training schedule

Manage public classes. Sunday = 0, Monday = 1, through Saturday = 6.

Merchandise

Manage listings and link to a real checkout page. This dashboard does not process payments.

Photo and video uploads

Uploads to the public fqmma-media bucket created by the updated SQL. Limit 50 MB per file. Use images or MP4/WebM video.

Membership records

Track plans and membership status. Status changes here are manual administrative records, not proof of payment. Connect a verified payment webhook before selling access.

Membership records

Live chat inbox

Inbox for signed-in users. Anonymous public visitor chat needs a separate rate-limited server endpoint.
